# Hero figure

`plate-5-3.png` is the Chladni figure on the landing page (mode (5,3) of a square plate). It is generated, not photographed: sand density follows `cos(5πx)cos(3πy) − cos(3πx)cos(5πy) ≈ 0`, with grain noise, on graphite `#181818`. Regenerate with `python3 scripts/make-plate.py`. No people, no logos, no text. Replace it with any square image to change the hero.
